welcome to my PHOSIMP Cheatsheet

PHOSIMP is an image filtering software available on Steam here

Filters

Negative

  • 000 - Regular Negative
  • 004 - Negative Range Filter ("Fancy" negative, how does this work!?)

Zoom

  • 605 - DANZOOM CENTER - IN
  • 606 - DANZOOM CENTER - OUT

Alpha / Transparency AKA Glowing

  • 346 - Remove alpha

Tiling

  • 016 - Hentaif Quadrant Pizza (Great for tiling IMO)

Blur - Spreading Sparse Images

  • [437-508] - SEVIL (Directional Blurs, different blur sizes are nested within each other - adds slight asymmetry)
Presets / Filter Combos

> A hollow circle bullet point indicates an optional step.

Creating Textures and Tiles

Use any mixture of these in any order to make low-res textured tiles.

  • Blur - spread color/light if the image is sparse - [437-508] - SEVIL (Blur)
  • Tiling - 016 - Hentaif Quadrant Pizza
  • Zoom - 605 - DANZOOM CENTER - IN
